# Midnight Slate

A dark theme for Visual Studio Code, primarily designed for C# and .NET development.

Midnight Slate combines a charcoal interface with muted accents and distinct syntax colors. It includes workbench, editor, and terminal colors, along with TextMate and semantic token highlighting.

The theme is primarily tuned for C# and .NET workflows, including Razor and related markup. Other languages use the same color palette, but have not been tested as extensively.
