# Changelog

## [0.2.0] - 2026-10-17

- Added Swift and SwiftUI highlighting.
- Refined the Source Control and diff colors for better readability.
- Added colors for gutter change indicators, breakpoints, and the overview ruler.
- Added Swift and SwiftUI screenshots and updated the Git diff screenshot.

## [0.1.1] - 2026-10-17

- Added screenshots and a recommended setup guide (icons, font, terminal) to the README.
- Enabled semantic highlighting by default in the theme.
- Moved the extension icons to `images/icons/`.
- Updated CI workflows to current GitHub Actions and Node.js 24.

## [0.1.0] - 2026-10-11

Initial release of Midnight Slate.

- Dark workbench, editor, and terminal color palette.
- TextMate and semantic token highlighting, primarily tuned for C# and .NET development.
- Additional syntax coloring for Razor, HTML, XML, JSON, YAML, CSS, Markdown, and other languages.
- Color definitions for supported VS Code extensions.
