# Changelog

## [1.0.0] - 2026-10-11

Initial release of Midnight Slate.

- Dark workbench, editor, and terminal color palette.
- TextMate and semantic token highlighting, primarily tuned for C# and .NET development.
- Additional syntax coloring for Razor, HTML, XML, JSON, YAML, CSS, Markdown, and other languages.
- Color definitions for supported VS Code extensions.
